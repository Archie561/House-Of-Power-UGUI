PlayerDataService відповідальний за усю маніпуляцію із даними гравця. Він містить методи для отримання даних PlayerData (PlayerData - клас усіх ігрових даних гравця) і надає доступ до їх зміни. Методи модифікації даних захищені через explicit implementation of the interface. Клас також відповідальний за збереження даних, функціонал для цього реалізовано в окремому класі SaveLoadSystem.

PlayerDataService is responsible for all manipulation of player data. It contains methods for retrieving PlayerData (PlayerData is the class that holds all player game data) and provides access to modify it. The methods for modifying data are protected through an explicit implementation of the interface. The class is also responsible for saving data; the functionality for this is implemented in a separate class, SaveLoadSystem.
